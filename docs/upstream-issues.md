# Upstream issue review

Spaceship Writer is an independent VS Code adaptation of [Spaceship IDE](https://github.com/chuanqisun/spaceship). The goal is to bring its steering interaction into the editor, where a writer can preview and apply a native edit to a manuscript. Chinese is one writing language, not a separate product edition.

| Upstream discussion                                                                          | What we took from it                                                                                                                                                                                                                                                                                     |
| -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [#1: Browser generation appears to stall](https://github.com/chuanqisun/spaceship/issues/1)  | The browser demo and the extension use different request paths; the extension host calls a configured local gateway. The common usability lesson is to make a failed continuation visible and recoverable without losing the manuscript. This is not a diagnosis or fix for the upstream browser report. |
| [#4: In-browser steering proof of concept](https://github.com/chuanqisun/spaceship/issues/4) | A useful comparison for previewing a change before applying it. Spaceship Writer already separates preview from applying a native editor edit. The experimental browser model, verifier and replay mechanism are not required for that workflow.                                                         |
| [#6: VS Code adaptation introduction](https://github.com/chuanqisun/spaceship/issues/6)      | The introductory release described its Simplified Chinese localization. Keep the project positioning focused on steering in VS Code; the writer's document and explicit direction should determine the language of a continuation.                                                                       |
