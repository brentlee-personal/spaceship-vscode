侧栏 03 · 强度表

仪表版。每行都有一条 10 格强度表，和续写旋钮上的关联标尺一样，每格代表 10%。亮格从靠近文本的一端向外逐格点亮，动效从焦点行向外扩散。行旁的括线标出各关键词框覆盖的范围，在关键词所在行加一道缺口；关键词列显示该框的排名及其关键词与续写点的相关度。

01实时

将指针悬停在主旋钮上，或按下 聚焦末端，即可查看各行与旋钮下方句子的关联度。将指针悬停在带底色的框上，即可查看各行与框内短语的关联度。 重新测量 模拟旋钮移动：决策 API 根据新的文本末端为每个关键词评估相关性。

02状态

03视觉编码

标尺
沿用方案 1 的条形标尺：主线贴着文本，每行一格，每五格标一个数字，续写点刻度为 1.5px。
括线
每个关键词框对应一条 ink-3 括线，跨过该框覆盖的所有行，并在关键词所在行留一个 1.5px 的缺口。指针悬停在框上时，对应括线变为橙色。
相关度列
显示该行关键词框内关键词的排名（ink-3）和分数（ink）；分数返回后更新排名。
强度表
共 10 格，间距 1px；熄灭时用 ink-5，点亮时用 ink-2。亮格数 = 行强度 × 10，四舍五入取整。新点亮的格子先闪一下橙色，再恢复常色。
焦点
焦点句旁的竖线加粗；仅显示焦点的行隐藏仪表，改为显示提示或关键词框。

04数据

关联
根据影响来源数据，逐句计算与焦点的关联强度。焦点是旋钮下的句子，或指针悬停的关键词框中的短语。每行对所含句子的强度按字符数加权平均。
相关度
由决策 API 逐一计算各框关键词与续写点（主旋钮下的句子）的相关度；旋钮移动时重新测量。
重构
两类焦点共用一个评分器，返回原始强度；对比度由侧栏调整，不在正文中调整。按行显示，按句评分。

05动效

0ms
焦点立即切换：指针悬停在关键词框或旋钮上时，关键词和括线立即变为橙色。
300 毫秒指数缓出
各行平滑过渡到新的强度，分数逐步变化至新值。
每行 18ms
从焦点句向外逐行错开，让更新从指针所在位置向外扩散。
上升时变为橙色
行内条形或分数上升时变为橙色，到达新值后恢复白色。数值下降或因离开焦点而归零时保持白色：用户已停止探查。
650ms（模拟）
决策 API 返回关键词相关度的延迟；分数返回前，分数位置以橙色脉动。
